This is an optional test release. Windows publisher signing is still pending.

Work Demands use Manual Data Entry or requests received from the Android app. Work Code, Work Name and Work Order are optional. Manual entry and Android request review share a compact worker list. Each worker keeps their own days and dates. The old printed-sheet, upload and OCR features have been removed. Android request PDF and Excel reports remain available.

Muster Roll Reports is part of the same desktop app, with the same sidebar, settings, sign-in, version and installer. Show or hide its menu in Settings, under Sidebar menus. Google sign-in opens the computer's usual browser.

Approve request now explains when the worker review cannot be opened and how to recover. An unanswered approval can be checked before trying again. Worker messages explain which record, filter or days balance needs attention and what to check next. Entered days and dates are kept during recovery.

Secretary login codes accept 4 to 32 characters, including symbols and spaces inside the code. Codes assigned to another account are refused across DEOs. Confirmed saved codes stay visible if a later list read fails. Use Read latest codes to check the list without repeating a save. Install the updated Android app before using the new characters.

The current personal Android access, Muster Roll Reports, account controls, referral links, PDF print preview and saved-record features are included. Review still requires Check demand before approval. Final official entry remains under the DEO's control.

Google sign-in is required before opening the app and saved records. If the computer's password storage is unavailable, the message explains how to enable or unlock it.

Keep the existing app and saved records when updating. On Linux, the Debian installer is recommended for Ubuntu 24.04. Linux updates are installed manually from these downloads. Google sign-in, portal Login, the Security Code and final official Submit stay under your control.

[Release notes](https://github.com/Changtey/Worker-Demand-releases/releases/tag/v1.4.10) explain the checks and remaining limits. Checksums are attached to each release. App building files stay on the owner's PC; no office records, passwords or signing keys are published here.
