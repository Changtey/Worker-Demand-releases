## What changed

- Settings has six clear categories, compact controls, Save and Cancel actions, and protection for unfinished changes.
- Work Demand Requests has a compact worker table, shared days and date controls, clear checks, approval and portal entry actions.
- Secretary login codes stay linked to the assigned Panchayat or Village. The DEO can read the codes directly in their management panel.
- Android worker selection shows names, Job Card numbers, eKYC and active-member status.
- Sent requests can be viewed, edited, updated, cancelled or deleted when permitted. Updates keep the same Request ID and use the existing online connection to the DEO.

The latest Settings change is for Windows. The Android file is the already checked 1.3.4 build.

## Install or update

1. Download the file for your device and open it.
2. Follow the device's installation steps. Keep saved app data when updating.
3. Existing supported app versions also check for updates at startup. Update later keeps the current app open. Installation remains your choice.

The Windows installer includes its required runtime. Saved records and protected login details are stored separately from the installed files. The Android package uses the same signing certificate as earlier public releases.

Read [START-HERE.md](https://github.com/Changtey/Worker-Demand-releases/releases/download/v1.3.6/START-HERE.md) for setup and [KNOWN-LIMITS.md](https://github.com/Changtey/Worker-Demand-releases/releases/download/v1.3.6/KNOWN-LIMITS.md) for remaining office checks.

The public repository contains installation files, instructions and update information. Private worker records, account credentials, Secretary codes and signing keys are not published. This is an independent tool, not an official government app.
